You can run my app two ways:
- Terminal
- Streamlit UI in your browser.


How to run:
- Clone the repo
- Create a venv (if u want to)
- Run pip requirements.txt
- Run code with:
  - Terminal: run "python main.py"
  - Streamlit: run "streamlit run app.py"
